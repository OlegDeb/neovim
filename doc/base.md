# Мои шпаргалки по Neovim

## 🚀 Основные маппинги
| Клавиша | Действие |
|---------|----------|
| `<leader>e` | Открыть/закрыть neo-tree |
| `<leader>w` | Сохранить файл |
| `<leader>q` | Закрыть окно |

## 📁 Файловый менеджер (neo-tree)
| Клавиша | Действие |
|---------|----------|
| `Enter` | Открыть файл/папку |
| `a` | Создать файл |
| `r` | Переименовать |
| `d` | Удалить |

## 🔧 Редактирование
| Команда | Действие |
|---------|----------|
| `yy` | Копировать строку |
| `p` | Вставить |
| `dd` | Удалить строку |
| `u` | Отменить |

## 📦 Плагины
| Плагин | Назначение |
|--------|------------|
| dracula/vim | Тема |
| neo-tree | Файловый менеджер |
